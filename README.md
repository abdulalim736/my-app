Project Name: Fitlog- Workout Library

Short Descriptions:
FitLog is a modern and responsive workout management application built with Next.js, React, TypeScript, and Tailwind CSS. It helps users explore workouts, create daily workout plans, save favorite exercises, and track completed workouts. FitLog provides a simple and organized way to stay consistent with fitness goals.

Technologies: Next.js · React · TypeScript · Tailwind CSS · Context API · Local Storage · React Hot Toast

5 Key Features

1. Workout Library: Explore a collection of workouts with detailed information, including muscle groups, equipment, difficulty, duration, and calories burned.
2. Today's Workout Plan: Add workouts to your daily plan and organize your training routine.
3. Save Favorite Workouts: Save your favorite exercises and access them anytime.
4. Workout Completion Tracking: Mark workouts as completed only once and track your daily progress.
5. Persistent Data & Responsive UI: Save workout plans using Local Storage so they remain available after refreshing the browser. Enjoy a responsive interface across mobile, tablet, and desktop devices.
